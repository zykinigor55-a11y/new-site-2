# СВОИ43 · прототип городской бьюти-платформы Кирова

Рабочая **демоверсия**, которую можно открыть в браузере. Это не опубликованный маркетплейс: мастера, цены, записи и примеры запросов вымышлены. Данные, которые вы создаёте, сохраняются **только в вашем браузере** (`localStorage`). Клиентка и мастер переключаются на одном устройстве, поэтому можно проверить весь демонстрационный сценарий.

## Запуск

1. Откройте `index.html` в современном браузере. Для онлайн-подложки реальной карты Кирова нужен интернет: тайлы загружаются с `tile.openstreetmap.org`. Если интернета нет, отображается **приблизительная, схематичная** подложка Кирова.
2. Более надёжный вариант: в папке проекта запустите `python -m http.server 8080`, затем откройте `http://localhost:8080`.
3. Для геолокации требуется разрешение пользователя и обычно **HTTPS** или `localhost`. Она работает только по нажатию ◎; при нахождении вне Кирова приложение не показывает вашу точку на городской карте.

## Что работает

- Режимы «Клиентка» и «Мастер».
- Интерактивная карта Кирова с перетаскиванием, масштабом, точками мастеров и приблизительными районами заявок; онлайн-подложка OpenStreetMap.
- Фильтры услуги, радиуса, времени, цены, поиск, выбор района и геолокация по согласию.
- Карточки мастеров, демонстрационные слоты, избранное.
- Клиентка создаёт заявку → мастер видит её в выбранном районе → откликается → клиентка принимает отклик → появляется тестовая запись.
- Мастер публикует свободное окно → клиентка видит его на карте.
- Профиль мастера, локальное сохранение и сброс данных.

## Чего пока нет

Реальных аккаунтов и регистрации, базы данных и сервера, сообщений между разными устройствами, оплаты, модерации, юридической проверки услуг, отправки SMS/Push, синхронизации с CRM и настоящего бронирования. Геолокация клиенток **никогда не показывается мастерам точными координатами**.

## Следующий шаг до реального запуска

Нужны backend, база данных, безопасная авторизация, хранение и удаление персональных данных согласно законодательству РФ, приватность местоположения, договор с картографическим провайдером (если необходимо), проверка специалистов, уведомления, правила отмен и модерация.
