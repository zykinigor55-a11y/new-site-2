# СВОИ43 — инструкции для Codex

Проект: демоверсия двухстороннего маркетплейса бьюти-услуг в Кирове (Россия).

## Технологии
- Vanilla HTML, CSS и JavaScript, без сборщика.
- Запуск: `python3 -m http.server 8080` и открыть http://localhost:8080.
- Главные файлы: `index.html`, `styles.css`, `app.js`.

## Сценарии
- Переключение клиент/мастер.
- Поиск мастеров по карте, услуге, району, цене и времени.
- Создание заявки клиентом, отклик мастера и принятие предложения.
- Свободные окна мастера и демонстрационные записи.
- Данные демоверсии находятся в localStorage браузера.

## Ограничения и безопасность
- Не выдавать демонстрационные записи, цены и профили за реальных людей.
- Запрашивать геолокацию только по явному действию пользователя.
- Не показывать точные координаты клиенток мастерам; для домашнего рабочего места требуется согласие на публикацию адреса.
- Не вводить серверные платежи или настоящую авторизацию без отдельной архитектуры, защиты данных и проверки требований законодательства РФ.
- Для карт используются OpenStreetMap tiles; перед публичным запуском проверить правила их использования и лицензии.

## Следующая разработка
1. Рефакторинг JS на модули и добавление простых smoke-тестов пользовательского сценария.
2. Доступность интерфейса и мобильная оптимизация.
3. Настоящая авторизация и серверное хранение с ролевой моделью, приватностью и модерацией.
4. Только после этого — публичный пилот в Кирове.
